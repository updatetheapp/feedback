# UpdateTheApp Feedback & Feature Requests

Welcome! This repository is the central place for submitting feedback, reporting issues (that aren't security vulnerabilities), and requesting new features for [UpdateTheApp.com](https://updatetheapp.com). We appreciate your input to help us improve!

## How to Contribute

The best way to provide feedback or suggest a feature is by **[opening a new issue](https://github.com/updatetheapp/feedback/issues/new/choose)** in this repository. We typically use the `enhancement` label for feature requests.

Please choose the appropriate issue template if available (e.g., "Feature Request", "Bug Report"). Using templates helps ensure you provide all the necessary information.

## Guidelines for Submitting Feedback

To help us understand and address your feedback efficiently, please:

1.  **Search Existing Issues:** Before creating a new issue, please check if a similar suggestion or report already exists. You can add your thoughts or 👍 to an existing issue.
2.  **Be Descriptive:** Provide as much detail as possible.
    *   For **feature requests**: Explain the problem you're trying to solve and how the proposed feature would help. Include potential use cases.
    *   For **bug reports**: Describe the issue clearly, include steps to reproduce it, mention your environment (e.g., browser, OS, relevant tool versions), and what you expected vs. what actually happened. Screenshots or screen recordings are often helpful.
3.  **Be Respectful:** Maintain a constructive and respectful tone in all communications.
4.  **One Issue Per Topic:** Please create separate issues for distinct topics (e.g., don't combine multiple feature requests into one issue).

## What to Expect

*   We monitor this repository regularly.
*   We will try to acknowledge new issues in a timely manner.
*   Feature requests and bug reports will be reviewed and prioritized based on various factors (impact, feasibility, alignment with our roadmap).
*   We may ask clarifying questions or provide updates on the status of your issue.
*   Please understand that not all feature requests can be implemented.
